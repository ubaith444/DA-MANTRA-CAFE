## 💼 Project Overview

This project focuses on transforming an underperforming café website into a **structured, user-friendly, and conversion-driven experience**.

The redesign emphasizes:
- Clear messaging
- Strong visual hierarchy
- Strategic call-to-actions (CTA)
- Mobile-first responsiveness

---

## 💣 Problem

The original website had:

- No clear value proposition  
- Weak or missing call-to-actions  
- Poor visual structure  
- No defined user journey  

👉 Result: Visitors left without taking action  

---

## ⚡ Solution

Redesigned the website using a **conversion-first approach**:

- Clean and structured layout  
- Clear hero section with CTA  
- Menu preview to guide decisions  
- Social proof (reviews + Instagram)  
- Strong location & contact section  

---

## 📈 Impact

- Improved clarity and readability  
- Better user flow and navigation  
- Increased potential for:
  - Café visits  
  - Calls  
  - Direction clicks
